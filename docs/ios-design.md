# iOS app design (`ios/`)

A UIKit client for X that runs on **iOS 12** (reference device: iPod touch 6th generation, iOS 12.5.7, 320×568 pt,
@2x, A8, 1 GB RAM) and looks and behaves like the official **Android** app. It talks only to the relay CGI
([`api-v2.md`](api-v2.md)); it never talks to X's API itself. Images and videos are loaded directly from X's CDN
(`pbs.twimg.com`, `video.twimg.com`).

The screens are specified in [`ui-spec.md`](ui-spec.md). This file covers the build, the layering and the shared
foundation every screen uses.

## 1. Hard rules

1. **Deployment target iOS 12.0, Swift 5, UIKit, no storyboards except the launch screen, no third-party code.**
   The CI compiles with Xcode 16.4 against the iOS 18 SDK, so an API newer than iOS 12 only compiles inside
   `if #available(iOS 13.0, *) { … }`. Never use, even guarded, as the only way to do something:
   `UIImage(systemName:)` / SF Symbols, `UIColor.label` and other semantic colours, `UIMenu`, `UIAction`,
   `UIButton.Configuration`, `UISheetPresentationController`, diffable data sources, compositional layout,
   `async`/`await`, Combine, SwiftUI, `UIScene`.
2. **What the CI shows must be what iOS 12 shows.** The only screens anyone can look at during development are CI
   screenshots from an iOS 18 simulator. Therefore the app draws its own chrome: its own top bars, bottom bar,
   icons, sheets and badges, built from plain `UIView`/`UILabel`/`UIButton`/Core Graphics. Do not rely on
   `UINavigationBar`, `UITabBar`, `UISearchBar`, `UISegmentedControl`, `UIAlertController(.actionSheet)` or
   `UIRefreshControl` *styling* for anything visible (their look differs between iOS 12 and iOS 18).
   `UIAlertController(.alert)` for confirmations and `UIRefreshControl` itself are fine.
   Scroll views: `contentInsetAdjustmentBehavior = .never` (inside `if #available(iOS 11.0, *)`), insets set by hand.
   Table views: `estimatedRowHeight = 0`, `estimatedSectionHeaderHeight = 0`, `estimatedSectionFooterHeight = 0`,
   and inside `if #available(iOS 15.0, *)` `sectionHeaderTopPadding = 0`.
3. **Layout is done in code with frames** (`layoutSubviews` / `viewDidLayoutSubviews`), using
   `view.safeAreaInsets`. No Auto Layout constraints in list cells (too slow on the A8 and hard to keep exact).
   Every screen must work at 320 pt width.
4. **Memory**: never decode a full-size photo. Images are downsampled while decoding to the size they are shown at.
5. **Text shown to the user is Japanese.** Code, comments and identifiers are English. Comment density and style
   follow the existing sources: short comments that say why, not what.
6. Settings survive the update: bundle id `com.mizuki20070314.XRelayClient`, `UserDefaults` keys `relayURL`
   (URL) and `profileName` (String), and the Keychain item of `KeychainTokenStore` are unchanged.
7. All completion handlers of the networking layer are called on the main queue. UIKit is touched on the main
   thread only.

## 2. Build and CI

- The Xcode project is generated by **XcodeGen** from `ios/project.yml` (every file under `ios/XRelayClient` is
  compiled/bundled; nobody edits a `.pbxproj`). Scheme and target: `XRelayClient`. `MARKETING_VERSION` 2.0.
  `ALWAYS_EMBED_SWIFT_STANDARD_LIBRARIES = YES` (iOS 12.0/12.1 have no Swift runtime), `TARGETED_DEVICE_FAMILY =
  "1,2"`, `UIRequiresFullScreen = true`, portrait only, `ENABLE_BITCODE = NO`, arm64.
- `.github/workflows/ios.yml` (runner `macos-15`, `/Applications/Xcode_16.4.app`):
  1. validate the Python CGI (`py_compile` + `unittest`),
  2. `brew install xcodegen`, `xcodegen generate` (in `ios/`),
  3. build for the simulator (Debug, `CODE_SIGNING_ALLOWED=NO`), print the compiler errors on failure
     (`grep -E "error:" | sort -u`),
  4. build for the device (Release, `iphoneos`, arm64, unsigned) and package `XRelayClient-unsigned.ipa`
     (`Payload/XRelayClient.app` at the top),
  5. boot the simulator **"iPhone SE (3rd generation)"**, run `tools/ci_screenshots.sh`, upload the PNGs as artifact
     `screenshots` (always, also when a step failed) together with crash reports,
  6. upload the IPA as artifact `XRelayClient-<sha>`.
- `tools/ci_screenshots.sh <XRelayClient.app> <simulator udid> [filter]`: installs the app and, for every shot,
  terminates the app, launches it with arguments, waits, saves `shots/<name>.png`
  (`xcrun simctl io <udid> screenshot`), and notes when the app is no longer running (a crash).

### Launch arguments (debug hooks, harmless in release)

| argument | effect |
|---|---|
| `-xr-demo` | no network: the relay client answers from the bundled demo JSON (`Resources/Demo`), images with the `demo://` scheme are drawn locally |
| `-xr-theme light\|dim\|black` | sets the theme before the UI is built |
| `-xr-size 320x568` | the window is that size, centred on the simulator screen, with a 20 pt top safe area (previews the iPod touch layout) |
| `-xr-route "step;step;…"` | drives the UI after launch, see `DebugRoutes` |

`DebugRoutes` (App layer): parses `-xr-route`, runs the steps one after another on the main queue (0.4 s apart;
`wait:<seconds>` adds a pause). A step is `name` or `name:argument`. Screens register their steps:
`DebugRoutes.register("tweet") { argument in … }`. Unknown steps are ignored.

## 4. Core

### 4.1 `JSON` — tolerant reader

The models are built by hand from `JSONSerialization` output through this wrapper (no `Codable`: one unexpected
`null` must not lose a whole timeline).

```swift
struct JSON {
    let raw: Any?
    init(_ raw: Any?)
    init(data: Data)                    // raw = nil when the data is not JSON
    subscript(key: String) -> JSON      // JSON(nil) when not an object / key missing
    subscript(index: Int) -> JSON
    var exists: Bool                    // not nil and not NSNull
    var string: String?
    var int: Int?                       // NSNumber or a numeric String
    var double: Double?
    var bool: Bool?
    var array: [JSON]                   // [] when not an array
    var dictionary: [String: Any]?
}
```

### 4.2 Models

Reference types for things that change while they are on screen (`Tweet`, `User`), values for the rest. Field
meaning is exactly api-v2.md §2.

```swift
    case notification(NotificationEntry)

struct ExploreTab { let id: String; let label: String }

```

`TweetStore.shared` keeps one instance per post id and per user id (weak references):
`func intern(_ tweet: Tweet) -> Tweet` returns the instance already known for that id after merging the new data
into it (or registers the new one); the same for `intern(_ user: User) -> User`. `Tweet.init` / `TimelineItem.init`
do **not** intern; `TimelinePage.init(json:)` interns every post (including quotes) and user it creates. Result: a
like made on the detail screen shows on the timeline behind it, because both hold the same object and observe
`Tweet.didChange`.

### 4.3 `RelayClient`

```swift
enum SearchMode: String { case top, latest, people, media }
enum UserTab: String { case posts, replies, media, likes }

enum TimelineSource: Equatable {
    case home(following: Bool)
    case tweet(id: String)
    case search(query: String, mode: SearchMode)
    case userTimeline(userID: String, tab: UserTab)
    case follows(userID: String, followers: Bool)
    case notifications(mentions: Bool)
    case bookmarks
}

final class RelayClient {
    static let shared: RelayClient

    // settings — storage identical to v1
    var baseURL: URL
    var isConfigured: Bool
    var profileName: String?
    private(set) var configurationRevision: Int
    func loadBearerToken() throws -> String?
    func saveSettings(baseURL: URL, profileName: String?, bearerToken: String?) throws
    func testConnection(baseURL: URL, profileName: String?, bearerToken: String?,
                        completion: @escaping (Result<[String], Error>) -> Void)        // GET /profiles

    // v2
    @discardableResult
    func timeline(_ source: TimelineSource, cursor: String?,
                  completion: @escaping (Result<TimelinePage, Error>) -> Void) -> URLSessionTask?
    func explore(tab: String?, completion: @escaping (Result<ExplorePage, Error>) -> Void)
    func me(completion: @escaping (Result<(user: User, badges: Badges), Error>) -> Void)
    func badges(completion: @escaping (Result<Badges, Error>) -> Void)
    func user(handle: String, completion: @escaping (Result<User, Error>) -> Void)
    func user(id: String, completion: @escaping (Result<User, Error>) -> Void)
    func setLike(tweetID: String, on: Bool, completion: @escaping (Error?) -> Void)
    func setRetweet(tweetID: String, on: Bool, completion: @escaping (Error?) -> Void)
    func setBookmark(tweetID: String, on: Bool, completion: @escaping (Error?) -> Void)
    func setFollow(userID: String, on: Bool, completion: @escaping (Error?) -> Void)
    func setMute(userID: String, on: Bool, completion: @escaping (Error?) -> Void)
    func setBlock(userID: String, on: Bool, completion: @escaping (Error?) -> Void)
    func createTweet(text: String, replyTo: String?, quote: String?,
                     completion: @escaping (Result<Tweet?, Error>) -> Void)
    func deleteTweet(id: String, completion: @escaping (Error?) -> Void)
}
```

- URL: `baseURL` + `/v2/…`; headers `X-Relay-Key`, `Authorization: Bearer`, `X-Profile-Name` (as v1's
  `addHeaders`). `URLSession` with a 30 s request timeout and **no** `URLCache` for API calls.
- Not configured → `.failure(APIError.notConfigured)` without a request.
- Non-2xx → `APIError` from the error body (api-v2.md §1): `unauthorized` → `.unauthorized`; `x_auth` →
  `.xAuth(message)`; `rate_limited` → `.rateLimited(message, retryAfter:)`; `not_found` → `.notFound(message)`;
  anything else → `.server(message)`. No connection → `.network(localizedDescription)`.
  `errorDescription` is Japanese (use the server's `message` when there is one).
- With `DebugFlags.isDemo` every call answers from `DemoData` after 0.05 s and never touches the network; the write
  calls succeed.

`Session.shared`: the logged-in account. `var me: User?`, `var badges: Badges`, `func refresh()` (calls `me`),
`func refreshBadges()`, `static let didUpdate: Notification.Name`. The last `/v2/me` answer is kept as JSON text in
`UserDefaults` (`cachedMe`) so the avatar and name are there at the next launch before the network answers.

### 4.4 Formatting (`Format`, Japanese, as the official app shows it)

```swift
enum Format {
    static func relativeTime(_ date: Date, now: Date = Date()) -> String
    // < 60 s: "5秒" (minimum "1秒"); < 60 min: "12分"; < 24 h: "3時間"; same year: "11月5日"; else "2025年11月5日"
    static func count(_ n: Int) -> String
    // < 10,000: "0", "999", "1,234"; < 1,000,000: "1万", "1.2万", "12.3万" (one decimal, ".0" dropped, truncated not rounded);
    // < 100,000,000: "123万", "1,234万"; else "1億", "1.2億"
    static func fullTimestamp(_ date: Date) -> String      // "午後7:05 · 2026年11月16日" (device time zone)
    static func joined(_ date: Date) -> String             // "2022年5月からXを利用しています"
    static func duration(ms: Int) -> String                // "0:19", "12:05", "1:02:03"
}
```

`TwitterText.weightedLength(_ text: String) -> Int`: X's post length. Each Unicode scalar counts 1 when it is in
U+0000–U+10FF, U+2000–U+200D, U+2010–U+201F or U+2032–U+2037, otherwise 2; every URL (`https?://…` up to the next
whitespace) counts 23 regardless of its length. The limit is 280.

### 4.5 Demo data

`Resources/Demo/*.json` are answers in the exact shape of api-v2.md, produced by `tools/make_demo_data.py` (invented
accounts and posts, Japanese text, no real people). They cover every feature the UI has to draw: the three badge
kinds, a square avatar, a label, a protected account, long text, 1/2/3/4 photos, tall and wide photos, video, GIF,
quote (with and without media, unavailable), cards (large, small, player, poll), reply with `reply_to`, repost,
pinned post, a joined thread, tombstone, `more`, `header`, counts from 0 to hundreds of millions, emoji, a URL, a
mention, a hashtag. The files are bundled flat, so every name starts with `demo_` (`demo_me.json`,
`demo_home_foryou.json`, …; the table below leaves the prefix out).
`DemoData.response(path: String, query: [String: String]) -> Data?` maps a request to a file:

| `/v2/search` | `search_<mode>.json` |
| `/v2/user` | `user_<handle>.json` when it exists, else `user_default.json` |
| `/v2/user/timeline` | `user_timeline_<tab>.json` |

Image URLs in the demo data use the `demo://` scheme: `demo://avatar/<n>`, `demo://photo/<n>?w=1200&h=800`,
`demo://banner/<n>`, `demo://card/<n>`. They are drawn by `DemoImages` (a soft two-colour gradient chosen by `n`,
for avatars with a white initial), so screenshots look like a real timeline without any network.

### 5.2 Icons

iOS 12 has no SF Symbols and fonts cannot provide these glyphs, so every icon is vector data drawn by the app.

- Source: the **Lucide** icon set (ISC licence; stroke icons on a 24×24 grid, stroke width 2, round caps and joins)
  plus a few shapes of our own. The licence text is in `THIRD_PARTY_NOTICES.md`. No artwork from X's apps.
- `tools/build_icons.py` reads `tools/icons/icons.json` (icon name → source SVG file in `tools/icons/svg/` or inline
  shapes) and writes `ios/XRelayClient/UI/Foundation/IconData.swift`. It converts every SVG element (`path` with
  all commands including arcs, `circle`, `ellipse`, `rect` with `rx`, `line`, `polyline`, `polygon`) into path
  strings that only contain absolute `M`, `L`, `C` and `Z` commands, so the Swift side needs a trivial parser.
- An icon is a list of layers; a layer is a path plus a drawing mode:

```swift
enum IconLayerMode { case stroke, fill, fillAndStroke, clearStroke, clearFill }   // "clear…" erases (CGBlendMode.clear) to cut a shape out of what is below
struct IconLayer { let path: String; let mode: IconLayerMode }

enum IconName: String, CaseIterable { … }      // generated

enum Icons {
    /// Template image (tint it with tintColor). `size` is the side of the 24-unit grid in points; `strokeWidth` is in grid units.
    static func image(_ name: IconName, size: CGFloat = 24, strokeWidth: CGFloat = 2) -> UIImage
}
```

  Images are rendered with `UIGraphicsImageRenderer` at the screen scale and cached by (name, size, stroke width).

### 5.3 Images

```swift
final class ImageLoader {
    static let shared: ImageLoader
    /// Loads, downsamples to at most `maxPixel` on the longer side (0 = 1024) and caches. Completion on the main queue.
    @discardableResult
    func load(_ url: URL, maxPixel: CGFloat, completion: @escaping (UIImage?) -> Void) -> ImageRequest?
    func cached(_ url: URL, maxPixel: CGFloat) -> UIImage?
    func clearCaches()
    var diskUsage: Int { get }
}
final class ImageRequest { func cancel() }

final class RemoteImageView: UIImageView {
    func setImage(url: URL?, maxPixel: CGFloat = 0)     // cancels the previous load; shows the cached image at once; fades a new one in (0.15 s)
}

final class AvatarView: UIView {
    var onTap: (() -> Void)?
    func set(user: User?, size: CGFloat)                // circle, or rounded square (radius size/6) for user.isSquare; placeholder colour until loaded
    func set(url: URL?, square: Bool, size: CGFloat)
}
```

- Memory: `NSCache` limited by cost (decoded bytes; 24 MB), emptied on a memory warning.
- Disk: its own `URLSession` with a `URLCache` (8 MB memory, 150 MB disk, in `Caches`).
- Decoding off the main thread with `CGImageSourceCreateThumbnailAtIndex` (`kCGImageSourceThumbnailMaxPixelSize`,
  `kCGImageSourceCreateThumbnailFromImageAlways`, `kCGImageSourceCreateThumbnailWithTransform`,
  `kCGImageSourceShouldCacheImmediately`).
- At most 4 downloads at a time; a cancelled request never calls its completion.
- `demo://` URLs go to `DemoImages.image(for: URL, maxPixel:)` instead of the network.

`Toast.show(_ text: String)`: a pill (accent background, white 14 pt text) at the bottom of the key window, above
the bottom bar, for 2 s.

`IconGalleryViewController`: a debug screen (route step `icons`) that shows every `IconName` at 24 pt with its name,
on the current theme, in a grid — the visual check of the icon set.
